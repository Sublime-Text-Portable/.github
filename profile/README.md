# Project Overview

Sublime Text is a fast and lightweight cross-platform text and source-code editor designed for programming, markup, scripting, and general text editing.

It combines responsive performance, syntax highlighting, powerful search tools, multiple selections, customizable shortcuts, plugins, and project management in a minimal development environment.

# Goto Anything

Goto Anything provides fast navigation across files, symbols, and lines within a project.

Combined with the Command Palette and keyboard shortcuts, it allows developers to navigate and execute common editor actions without relying heavily on menus.

---

# Multiple Selections

Multiple selections are one of Sublime Text's most useful editing features.

Developers can edit several locations simultaneously, rename repeated values, modify matching text, and perform repetitive editing operations with fewer manual steps.

# Performance

Sublime Text is designed around responsive editing and can handle many everyday programming and text-processing workflows with relatively modest resource usage.

Performance can still depend on file size, project complexity, syntax definitions, plugins, and background indexing.

---

# Troubleshooting

If Sublime Text becomes slow or unstable, review recently installed packages, project size, syntax configuration, build processes, and available system resources.

Plugin conflicts can often be diagnosed by temporarily disabling nonessential packages.

Keep important source code under version control and maintain backups where appropriate.
